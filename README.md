# IntelLauncher
Launcher Android experimental em Kotlin/Jetpack Compose. Navegação horizontal entre Workspace, Home e Intelligence. O painel CTI não exibe dados reais nesta versão.

## APK
Abra a aba Actions, selecione Build IntelLauncher APK e baixe o artefato após a execução. APK de depuração para testes; não é versão de produção.

## Privacidade
Não solicita permissões de rede ou acesso a calendário. A lista de apps é obtida localmente.
